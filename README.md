A tiny deterministic program that writes one roast of the smartwatch to `/output/entry.txt`: it watches you sit for eight hours, then buzzes to congratulate you for standing up — eight hours of surveillance, one second of applause. One line, 148 characters, one gadget, one absurdity.

## Run it

```sh
python3 main.py
```

The program validates the roast against the gate (1–200 characters, a single line of UTF-8 text, not blank) and writes it to `/output/entry.txt` (or `$OUTPUT_DIR/entry.txt`).
